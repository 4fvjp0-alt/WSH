# 로컬 세션용 프롬프트 — 우시오 스타일 케이스 옵션별 실제 가격 확인

아래 내용을 로컬 Claude Code 세션(Claude in Chrome 사용 가능)에 그대로 붙여 넣으세요.

---

Claude in Chrome으로 내 크롬(로그인된 상태)에서 AliExpress 상품 6개를 열어, 아래 기준대로 옵션을 직접 골라 **실제 결제 전 가격**을 확인하고 비교표를 만들어 줘.

## 규칙
- 내 탭은 건드리지 말고 **새 탭**에서 작업해 줘. 상품 하나 확인이 끝나면 그 탭은 닫아도 돼.
- **장바구니 담기·구매·결제 버튼은 절대 누르지 마.** 옵션만 선택해서 화면에 표시되는 가격만 읽어 줘.
- 로그인, 캡차, 본인 확인 화면이 나오면 멈추고 나에게 알려 줘. 우회하지 마.
- 쿠폰을 받거나 적용하지 마. 화면에 이미 반영된 할인가만 기록해 줘.

## 옵션 선택 기준 (우시오 스타일)
| 항목 | 고를 것 | 피할 것 |
|---|---|---|
| 크기 | 40mm | 36mm, 39mm, 41mm 이상 |
| 크리스탈 | 사이클롭스 없음 (No magnifier / Flat / 확대경 없음) | With cyclops / Magnifier |
| 베젤 | 블루 세라믹 다이버(60분 눈금) | GMT 24시간, 투톤(Batman·Pepsi) |
| 브레이슬릿 | 오이스터(3열) | 주빌리(5열), 스트랩만, 브레이슬릿 없음 |
| 다이얼 크기 | 28.5mm | 29mm, 31mm |
| 크라운 | 3시 | 3.8시 |

- 블루 다이버 베젤 옵션이 없으면 **블랙 다이버 베젤**로 고르고 "블루 인서트 별도 필요(약 ₩10,000)"라고 표시해 줘.
- 사이클롭스 없는 옵션이 아예 없으면 그 사실을 적어 줘.
- 기준에 맞는 조합이 여러 개면 가장 싼 것을 기록해 줘.

## 결과 형식
1. 상품별 표: 선택한 옵션 이름(화면 표기 그대로), 표시 가격(원), 배송비, 재고 여부, 블루 인서트 필요 여부, **실제 총액**(가격 + 배송비 + 필요 시 인서트 ₩10,000)
2. 각 상품의 옵션 선택 화면 스크린샷 1장씩
3. 실제 총액 기준 순위와 추천 1개 (이유 한 줄)
4. 결과를 `watch_mod/ushio/cases/option_prices.md`로 저장하고 커밋·푸시 (브랜치 `claude/disk-space-analysis-jONGY`)
