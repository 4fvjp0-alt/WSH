1. 평판 위 흐름 — h(x)와 δ(x)

Laminar 에서 δ↑ → h↓  why?

  • 표면 근처의 열저항 증가
  • 벽면 온도 구배(∂T/∂y) 완화
열은 벽 바로 위 얇은 층에서 전도로만 빠져나감.
층이 두꺼워지면 = 담요가 두꺼워진 것 → 열이 덜 나감.
h ≈ k / δt (p.5에서 증명!)
Turbulent: 소용돌이가 뜨거운 유체 ↔ 차가운 유체를 막 섞어줌(mixing) → 벽 근처 온도 구배가 다시 가팔라짐 → 천이 구간에서 h가 갑자기 커짐.
그 뒤 난류 안에서도 경계층이 두꺼워지니 h는 다시 천천히 감소.

✎ 원래는 수식적으로  PDE → ODE → "Blasius(블라시우스)"로 풀이 (p.6~에서 자세히)

4. Order of Magnitude (차수 해석)

정확한 계산 대신 러프한 계산 → "대충 몇 배 정도?"만 본다.

예) 소금쟁이가 물에 뜨는 이유 — 무게 vs 표면장력의 크기(차수)만 비교해도 답이 나옴

왜 하냐면? 정확한 해(Blasius)는 계산이 길고 복잡. 근데 차수 해석만 해도 Re−1/2 같은 "지수"는 정확히 맞힌다! 틀리는 건 앞의 숫자(계수)뿐.

속도 Hydrodynamic B.L.

• Viscous diffusion length (점성 확산 거리)

δ ∝ ν t
"확산 거리 ~ √(확산계수 × 시간)" — 이건 외우기!
물에 잉크 한 방울: 처음엔 빨리 퍼지다가 점점 느려짐 (√t 처럼).
여기선 벽의 "멈춤 효과"가 점성(ν)을 타고 위로 퍼져나가는 것.

• 시간 t는? → 유체가 앞전에서 x까지 오는 데 걸린 시간

t ≈ xU∞  ⟹  δ ≈ ν · xU∞

• 레이놀즈수 Rex = U∞ xν   (관성력 / 점성력) 를 써서 정리하면

δ ≈ ν xU∞ = x · νU∞x = xRex   ∴  δx ∝ 1Rex

⇒ 정확한 해와 비교:  exact sol:  δx = 5Rex  ← 계수만 1→5!

🔢 감 잡기 예시  공기 ν ≈ 1.5×10−5 m²/s, U∞ = 5 m/s, x = 0.5 m
Rex = 5×0.5 / 1.5×10−5 ≈ 1.7×105 (아직 층류, 5×105 미만)
δ = 5x/√Re ≈ 5×0.5/408 ≈ 6 mm → 경계층은 정말 얇다!
δ ∝ √x → 뒤로 갈수록 두꺼워지지만 점점 천천히 두꺼워짐 (p.1 그래프의 δ(x) 모양)

5. Self-Similar Solution (Blasius 상사해)

이제부터는 "정확한 해" 파트. 목표: 앞에서 나온 숫자 5, 0.332, 0.664가 어디서 나오는지!
전략 = 어려운 PDE(편미분방정식)를 → 변수 하나짜리 ODE(상미분방정식)로 바꿔서 푼다.

조건: Laminar flow, constant free stream velocity U∞ on a plate (L: length)
     ρ, μ : const. ,  2-D steady-state

① 지배방정식 (Navier–Stokes + 연속)

x:  u∂u∂x + v∂u∂y = −1ρ∂p∂x + ν(∂²u∂x² + ∂²u∂y²) y:  u∂v∂x + v∂v∂y = −1ρ∂p∂y + ν(∂²v∂x² + ∂²v∂y²) 연속:  ∂u∂x + ∂v∂y = 0   ; mass conservation (∵ ρ = const)

좌변 = 관성(흐름이 실어 나르는 것), 우변 = 압력 + 점성(마찰로 퍼지는 것)

② 무차원화

ū = uU∞,   v = vU∞,   x = xL,   ȳ = yL,   p = pρU∞2 ū∂ū∂x + v∂ū∂ȳ = −∂p∂x + νU∞L(∂²ū∂x² + ∂²ū∂ȳ²)   ν/(U∞L) = 1/ReL (y식도 같은 방식)
무차원화를 왜 해? 각 항의 크기를 비교하려고!
경계층은 얇아서 ȳ ~ δ/L ~ ReL−1/2 (아주 작음), v ~ δ/L 도 작음 →
• ∂²ū/∂x² ≪ ∂²ū/∂ȳ² → x방향 점성항 버림
• y-운동량식 → ∂p/∂y ≈ 0 → 압력은 y로 일정 = 바깥 흐름 압력
• 평판 + U∞ 일정 → dp/dx = 0
∴ 경계층 방정식:   u∂u∂x + v∂u∂y = ν∂²u∂y²

③ 상사변수 η 도입 (PDE → ODE의 핵심!)

δ ~ νxU∞  (p.3 결과)   ⇒   η = yδ(x) = yνx / U∞
"Self-similar(상사)"의 뜻
x마다 경계층 두께는 다르지만, y를 그 위치의 δ로 나눠서(=η) 그리면 모든 속도 분포가 똑같은 곡선 하나로 겹친다!
→ 그래서 u/U∞는 x, y 따로가 아니라 η 하나만의 함수.
ū = uU∞ = φ(η) = f′(η),    f′ = ∂f∂η = φ

f(η) = 무차원 유선함수: ψ = √(νxU∞)·f(η), u = ∂ψ/∂y = U∞f′ → 연속방정식 자동 만족!

체인룰로 미분 바꾸기

∂ū∂x = ∂φ∂η·∂η∂x = −12x η φ′ = −η2x f″    (∵ η ∝ x−1/2) ∂ū∂y = f″ · 1δ,    ∂²ū∂y² = f‴ · 1δ² ,   ⋯ (경계층 방정식에 대입) f‴ + 12 f f″ = 0   ← Blasius 방정식 (ODE!)

(교재에 따라 2f‴ + f f″ = 0 으로 쓰기도 함 — 같은 식)

④ 경계조건 (BCs)

물리적 조건η로 바꾸면f로 쓰면
y = 0 : u = 0 (no slip)η = 0f′(0) = 0
y = 0 : v = 0 (벽 뚫고 못 나감)η = 0f(0) = 0
y = ∞ : u = U∞η = ∞f′(∞) = 1
⚠ 필기 수정 — 노트에 "y = ∞ → u = ∞"라고 적혀 있는데 u = U∞ (자유흐름 속도) 입니다. 속도가 무한대가 되는 게 아니에요!

6. 온도 경계층의 상사해

2-D steady-state 에너지 방정식

u∂T∂x + v∂T∂y = α(∂²T∂x² + ∂²T∂y²)

운동량식이랑 모양이 똑같다! (ν ↔ α, u ↔ T)

θ = T − TwT∞ − Tw   → 무차원화해서 속도랑 똑같이 풀 수 있게 만들기

θ는 벽에서 0, 바깥에서 1 → ū(=u/U∞)도 벽에서 0, 바깥에서 1. 완전히 같은 꼴!

ū∂θ∂x + v∂θ∂ȳ = αU∞L(∂²θ∂x² + ∂²θ∂ȳ²) ← 경계층 근사로 x항 삭제
ū∂θ∂x + v∂θ∂ȳ = αU∞L∂²θ∂ȳ²
B.Cs
y = 0 → θ = 0  (∵ T = Tw)
y = ∞ → θ = 1  (∵ T = T∞)

η = η(x, y) 로 바꾸면 → ODE

∂θ∂x = ∂θ∂η·∂η∂x,   ∂θ∂y = ∂θ∂η·∂η∂y  ⇒  θ″ + Pr2 f θ′ = 0
Pr = 1 (α = ν) 이면? → θ식과 속도식(f′에 대한 식)이 완전히 같아짐 → θ = f′(η), δ = δt
α ≠ ν 이면? → 두 경계층 두께가 달라짐:  δt/δ = Pr−1/3,  δ/δt = Pr1/3

그래서 필기처럼 ηT = η · Pr1/3 로 "늘려서" 보면 (근사적으로)

∂²θ∂ηT2 + 12 f(ηT) ∂θ∂ηT = 0,    (ηT=0: θ=0,  ηT=∞: θ=1)

→ Pr=1일 때와 같은 꼴의 식 = 이미 풀어놓은 답을 재활용! (ηT는 "온도용 η"라고 생각)
